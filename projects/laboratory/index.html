01 — ARCHITECTURE

Small pieces.
Clear responsibilities.

The stack is intentionally compact so you can follow one request from the API, through metrics collection, into a dashboard or alert. All host ports are bound to localhost.

COMPONENT / 01

Python API

HTTP service with health/readiness probes, JSON responses, request counters, and duration histograms.

api/app.py
COMPONENT / 02

Prometheus

Scrapes metrics every 10 seconds and evaluates service-down, elevated 5xx, and latency alert rules.

prometheus/*.yml
COMPONENT / 03

Grafana

Reads a provisioned Prometheus datasource and loads the platform observability dashboard from version-controlled JSON.

grafana/dashboards/
COMPONENT / 04

Compose + CI

Local orchestration, localhost-only port publishing, an isolated API container, automated unit checks, and end-to-end service smoke checks in CI.

docker-compose.yml
!
Scope and safety, intentionally explicit

This lab has no TLS termination, authentication proxy, Alertmanager notification route, durable application metrics, or production SLO policy. It is a local learning stack. The example error/slow endpoints exist to make signals visible and should not be exposed publicly.

02 — QUICK START

Bring the Laboratory online.

Run these commands from the projects/laboratory/ directory. You need Docker Engine and Compose v2. Create a local Grafana password first; the example file is a template, not a secret.

03 — API CONTRACT

Signals you can trigger.

The HTTP route labels are deliberately bounded to prevent arbitrary path values from creating unbounded Prometheus time-series cardinality.

GET
/healthz

Liveness check. Returns a small successful JSON response.

GET
/readyz

Returns HTTP 503 when `SERVICE_READY=false`; liveness stays independent.

GET
/metrics

Prometheus exposition endpoint. Scrapes are intentionally excluded from request counters.

GET
/demo/error

Intentional HTTP 503 response to exercise error-rate panels and alert queries.

GET
/demo/slow?seconds=1.5

Bounded 0–3 second delay to generate latency samples.

GET
/

JSON service overview, version, uptime, and endpoint list.
