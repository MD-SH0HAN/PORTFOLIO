## Verification and closure

- How was the expected behavior verified?
- What negative/failure case was tested?
- What was cleaned up, and how was cleanup confirmed?
- What did this exercise not test?
- What would I change in a repeat attempt?
- What can I now explain or reproduce independently?
- What is the next learning objective?

## Claim rule

Only describe an exercise as reproduced after performing it and retaining observed evidence. Only describe an implementation as verified when its source/configuration and relevant tests can be independently inspected. Never convert a conceptual explanation or browser simulation into a deployment claim.
