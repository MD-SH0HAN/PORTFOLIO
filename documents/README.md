# Portfolio documents

- `technical-portfolio-print.html` — print-ready technical portfolio master. The downloadable `assets/MD-SHOHAN-DevOps-Portfolio.pdf` is generated from this master.
- `one-page-profile-print.html` — compact profile print master.
- `engineering-playbook/` — practical study runbooks and an evidence-record template. These materials are explicitly learning resources, not proof of completed production work.

When updating the technical print master, regenerate the PDF from it and inspect the resulting page count, text extraction and page renders before publishing. The PDF is a snapshot; the HTML master remains the editable source.
